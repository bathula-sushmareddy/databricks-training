# Output Files

This folder contains the generated outputs and screenshots from the Phase 4A – Bucketing & Segmentation project.

## Files

### conditional_segmentation.png
Displays the customer segmentation using fixed spending thresholds (Gold, Silver, Bronze).

### customer_count_by_segment.png
Shows the number of customers in each segment.

### quantile_segmentation.png
Displays customer segmentation using quantile-based thresholds.

### bucketizer_output.png
Shows the output generated using PySpark MLlib Bucketizer.

### window_percent_rank.png
Displays customer rankings calculated using the `percent_rank()` window function.

### comparison.png
Compares the results of conditional segmentation and quantile-based segmentation.
