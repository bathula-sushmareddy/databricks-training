# SQL to PySpark – Phase 3: Final ETL & Pipeline

## Objective

This project focuses on building a complete ETL (Extract, Transform, Load) pipeline using PySpark while converting SQL queries into equivalent PySpark DataFrame operations. It demonstrates real-world data engineering concepts using Spark Playground sample datasets.

## ETL Workflow

### Extract

- Read CSV datasets from `/samples/`
- Inspected data using `show()` and `printSchema()`
- Demonstrated reading JSON and Parquet files

### Transform

- Removed null values
- Filtered invalid records
- Converted data types
- Joined customer and sales datasets
- Performed aggregations and business analysis

### Load

- Displayed transformed results
- Generated final reporting table
- Saved output screenshots

---

## SQL to PySpark Exercises

### 1. Daily Sales

Calculate total sales for each day.

### 2. City-wise Revenue

Calculate total revenue generated by each city.

### 3. Repeat Customers

Identify customers with more than two orders.

### 4. Highest Spending Customer

Find the highest spending customer in every city.

### 5. Final Reporting Table

Generate a business reporting table containing:

- Customer ID
- Customer Name
- City
- Total Spend
- Order Count
